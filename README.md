# 🎬 Universal Telegram Video Downloader Bot with Forced Subscription

Полноценный, асинхронный Telegram-бот на **Python 3.12+** и **aiogram 3** для скачивания видео из **YouTube**, **Instagram (Reels)**, **TikTok** и **Pinterest** с обязательной проверкой подписки на ваши Telegram-каналы.

---

## 🌟 Возможности
* **Проверка подписки**: Пользователь должен подписаться на ваши каналы, прежде чем скачать видео.
* **Мультиплатформенность**: YouTube, Instagram, TikTok, Pinterest.
* **Выбор качества**: 360p, 720p, 1080p, Авто.
* **Двуязычность**: Русский и Тоҷикӣ.
